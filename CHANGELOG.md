# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [semantic versions](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-22

### Added

- Modularity module for a grid of link cards with titles, descriptions, links, and icons.
- A choice of two, three, or four columns.
- A color theme field with preset themes and custom colors.
- Swedish translation.
- Project instructions for AI tools.

### Fixed

- Empty card rows and unexpected field values no longer stop the module from rendering.
- The color theme field keeps its value when the block editor remounts the form.
- Link card styles load in the block editor as well as on the front end.
